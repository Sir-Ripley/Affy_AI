## 2024-05-24 - [Allocation-Free String Building]
**Learning:** Chaining `.filter { ... }.joinToString { ... }` in Kotlin eagerly evaluates and creates intermediate list allocations. In frequently evaluated properties (like `GenerateContentResponse.text` which is constantly evaluated during streaming responses), this creates unnecessary garbage collection overhead.
**Action:** Use `buildString { ... }` and manual iteration (`for`) to append string parts dynamically without creating intermediate collections. Always preserve exact exception behavior (e.g., throwing `NoSuchElementException` on empty collections instead of returning `null`) during optimizations.
